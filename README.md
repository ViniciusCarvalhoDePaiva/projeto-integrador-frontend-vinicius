# Comparador de Planos de Streaming

Projeto desenvolvido para a disciplina de Desenvolvimento Front-end para Web.

## Objetivo e Público
Ajudar consumidores brasileiros a comparar preços, recursos e condições dos principais serviços de streaming de forma simples, leve e transparente.

## Funcionalidades Principais (Versão Base)
- Dicas rápidas para economizar em assinaturas.
- Tabela comparativa de planos básicos (preço de referência, telas simultâneas e presença de anúncios).
- Link direto para o portal Consumidor.gov.br.

## Como visualizar o projeto
1. Baixe ou clone este repositório.
2. Abra o arquivo `index.html` diretamente no seu navegador.

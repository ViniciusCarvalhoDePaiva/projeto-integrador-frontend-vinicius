# Comparador de Planos de Streaming

Projeto Integrador da disciplina de Desenvolvimento Front-end para Web, construído com HTML5, CSS3 e JavaScript puro.

## Objetivo e público-alvo

O site foi criado para ajudar consumidores comuns, estudantes e famílias a comparar preços, quantidade de telas simultâneas, presença de anúncios e custo por tela dos principais serviços de streaming no Brasil, facilitando a escolha do plano que faz mais sentido para o bolso.

## Funcionalidades principais

- **Navegação fixa (sticky) com dropdown:** facilita o acesso rápido às seções da página durante a rolagem.
- **Grade responsiva e tabela comparativa:** apresenta os planos em destaque (com CSS Grid) e uma tabela com valores de referência.
- **Gráfico visual em Canvas 2D:** compara os preços mensais de forma animada.
- **Lista interativa com JavaScript e DOM:** permite filtrar planos em tempo real, favoritar, remover e adicionar novos planos com cálculo automático de custo por tela e resumo atualizado na hora.
- **Formulário de recomendação e dicas:** reúne orientações para economizar e um formulário demonstrativo de preferências.
